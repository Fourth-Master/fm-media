# FM影媒（iOS）

一款把「本机目录 + 媒体服务器 + 云盘 + WebDAV/SMB」聚合到一起的 iOS 媒体库与播放器。
以「番号」为目录约定，自动识别封面、大图、NFO、预览截图与字幕，支持在线搜索字幕并逐项调整字幕样式与时间轴。

- 平台：iOS 15.4+（iPhone / iPad）
- 技术栈：SwiftUI + MPV(libmpv) + MobileVLCKit，无第三方运行时依赖
- 工程：Xcode 16 及以上（工程使用 Xcode 16 的文件夹同步格式）

---

## 一、快速开始

1. 用 Xcode 16 打开 `FMMedia.xcodeproj`。
2. 选择 `FMMedia` scheme 与一台 iOS 15.4+ 模拟器或真机。
3. 真机运行需要在 `Signing & Capabilities` 里选择自己的 Team（Bundle ID 默认 `com.fmmedia.fmplayer`，可自行修改）。
4. ⌘R 运行。

> 如果不打算上架、只想装在越狱/TrollStore 设备上，可以直接用下面的「GitHub 构建 + 巨魔安装」流程，无需开发者账号。

> 如果用 Xcode 15 及更早版本打开失败，可改用仓库根目录的 `project.yml` 配合 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 生成工程：
> `xcodegen generate`。

首次启动后：

1. 「文件 → 添加来源」→ 选择「本机目录」，挑选一个按番号命名的文件夹；
2. 回到「首页 / 媒体库」，点右上角刷新即可扫描；
3. 也可以添加 Emby / Jellyfin / WebDAV / 云盘等远程来源，在「文件」中浏览并播放。

### 免签安装（TrollStore / 巨魔）

本机 Mac 上运行 `./scripts/build-ipa.sh` 一键生成免签 IPA。

详细步骤见 [`docs/TrollStore安装.md`](docs/TrollStore安装.md)。

## 三、番号命名规则（核心）

扫描器严格按以下约定识别媒体：

```
ABC-123-uc/                  ← 番号文件夹（-u / -c / -uc 为可选标记）
  ABC-123.mp4                ← 正片：文件名同为番号
  ABC-123.srt                ← 字幕：文件名同为番号
  ABC-123-poster.jpg         ← 小封面（竖版海报）
  ABC-123-fanart.jpg         ← 大封面（横版背景图）
  ABC-123.nfo                ← 影片信息（Kodi / Emby 兼容 XML）
  extrafanart/               ← 预览截图目录
    0.jpg
    1.jpg
    2.jpg
```

| 命名 | 含义 |
| --- | --- |
| `xxx-123` | 基本番号 |
| `xxx-123-u` | 破解（`u`，不区分大小写） |
| `xxx-123-c` | 字幕（`c`，不区分大小写） |
| `xxx-123-uc` / `-cu` | 同时为「破解」和「字幕」 |
| `xxx-123-poster.*` | 小封面，支持 jpg/jpeg/png/webp/heic |
| `xxx-123-fanart.*` | 大封面 |
| `xxx-123.nfo` | 影片信息；也兼容 `movie.nfo` |
| `extrafanart/0.jpg` | 预览截图，按文件名数字从 0 开始排序 |

补充规则：

- 番号格式：2–6 位字母 + 2–5 位数字，分隔符支持 `-` `_` `.` 与空格，例如 `ABC-123`、`abcd-12345`；
- 正片/字幕文件按「番号一致」匹配，即 `ABC-123-u.mp4` 也会归入 `ABC-123`；
- 文件夹名不符合规则但含视频时，会作为「未识别」条目出现在媒体库（可在设置中隐藏）；
- 支持根目录散落文件：同一番号的视频、字幕、封面会自动聚合为一个条目。

### 3.1 重复番号检测与清理

「设置 → 媒体库 → 重复番号检测」会按番号分组列出重复条目，并自动给出保留/清理建议：

1. 优先保留带「破解」「字幕」标签的影片；
2. 其次比较封面、大图、NFO 数据源与预览图是否齐全；
3. 最后按文件体积（清晰度）取舍，看过的影片额外加分不会被清理。

清理时可勾选「同时删除远程服务器文件」：

- 本机影片：删除视频、同番号封面/大图/NFO/字幕与 extrafanart 目录，目录清空后连同目录删除；
- Emby / Jellyfin：调用 DELETE /Items/{id} 删除条目与文件（账号需有删除权限）；
- WebDAV / SMB：独立番号目录整体删除，共享目录只删对应番号的文件；
- 不勾选时，远程条目仅从媒体库移除；删除失败的条目会保留并给出原因。

### 3.2 标题显示与题材分类

「设置 → 媒体库 → 标题显示」提供三种模式，卡片与详情页立即生效：

| 模式 | 大标题 | 小标题 |
| --- | --- | --- |
| 原名 + 简介（默认） | 数据源 `originaltitle` | 截取简介（plot）开头 |
| 标题 + 演员 | 数据源 `title` | 前 3 位演员 |
| 自定义组合 | 勾选字段组合（可多选） | 勾选字段组合（可多选） |

- 数据源缺失或不完整时自动逐级回退：originaltitle → title → **番号**；
- 「标题完整显示」开关：打开后卡片标题多行不截断，网格按行顶部对齐（行内高度一致，不会参差）；
- 自定义模式：在设置里勾选「大标题字段 / 小标题字段」，可选 originaltitle、title、番号、简介开头、演员，多选用「 · 」连接；
- 「启用题材分类」打开后，媒体库顶部会出现题材筛选条（按数据源 genre 汇总，最多 12 个）。

首页「继续观看」卡片**长按**可以「移出播放记录」（只清进度，不删文件）。

## 四、字幕

### 4.1 在线搜索

播放器与详情页均提供「搜索字幕」，会同时查询：

1. `https://api-shoulei-ssl.xunlei.com/oracle/subtitle?name=番号`
2. `https://subtitlecat.com/index.php?search=番号`

搜索结果按语言优先排序，点击即下载、保存到本机并自动应用。SubtitleCat 的部分字幕为压缩包，遇到时会提示改用「导入字幕」。

> 两个站点均为第三方服务，接口可能随站点调整而变化；解析层已做容错，但对返回格式的变化无法保证长期有效。

### 4.2 字幕调整

播放器右上角「字幕样式与同步」可实时调整：

- 字号、粗体、斜体、大写
- 文字颜色、描边颜色、描边宽度
- 背景不透明度、底部距离
- 时间轴偏移（±10 秒，步进 50ms，支持 ±0.1s / ±0.5s 快捷键）

字幕由自绘覆盖层渲染，因此 ASS/SSA 的基础样式（斜体、粗体、换行）与任意 SRT 都能统一调整；ASS 的定位、动画等高级标签会被忽略。

### 4.3 字幕来源

- 同级目录同名字幕（自动加载）
- 视频内嵌字幕（AVPlayer legible track）
- 在线下载并关联到影片
- 手动导入本地字幕文件

## 五、播放内核（全格式播放）

App 内置两套解码内核，可在「设置 → 播放 → 播放内核」切换：

| 内核 | 说明 |
| --- | --- |
| MPV（libmpv，默认） | FFmpeg + VideoToolbox，OpenGL ES 渲染；格式覆盖最广（MKV/AVI/RMVB/WMV/FLV/TS/M2TS/ISO/VOB…） |
| VLC（MobileVLCKit） | 备选内核，MPV 失败时自动切换 |
| 自动 | MPV 优先，失败自动回退 VLC 并从当前位置续播 |

> AVPlayer 已移除：它支持的容器太少，无法满足全格式播放。


内核之外还有独立的**解码方式**开关（设置 → 播放 → 解码方式，或播放中「更多」菜单临时切换）：

| 解码方式 | 行为 |
| --- | --- |
| 自动（默认） | 优先 VideoToolbox 硬解，失败自动回退 CPU 软解 |
| 硬件解码 | 强制 VideoToolbox，省电；个别编码（如部分 10-bit/AV1）可能失败 |
| 软件解码 | 纯 CPU 解码，兼容性最好，耗电更高；适合硬解花屏/黑屏的文件 |

实现在 `VLCPlayerEngine`：通过 libvlc 的 `:avcodec-hw=any|videotoolbox|none` 生效；
硬解报错时会自动用软解从当前位置重试一次，并提示「硬件解码失败，已切换为软件解码」。

实现要点：

- `Core/Player/PlaybackEngine.swift` 定义统一内核协议，`AVPlayerEngine` 与 `VLCPlayerEngine` 各自实现，`PlayerViewModel` 只做状态聚合与字幕；
- 拖入 MKV 时，`自动` 模式直接选 VLC；远程流没有扩展名时先试系统内核，出错或 15 秒无画面则自动回退，播放器顶部会提示「已切换到 VLC 内核」；
- 播放器右上角会显示当前内核名称，出错浮层还提供「用 VLC 重试」；
- 字幕仍由 App 自绘，VLC 的标题/OSD 与外挂字幕自动加载均已关闭，因此所有字幕调整项对两种内核一致生效。

播放器手势：

| 操作 | 效果 |
| --- | --- |
| 左右滑动 | 快进 / 倒退（约 3 分钟/整屏宽度，松手生效） |
| 左侧上下滑动 | 屏幕亮度 |
| 右侧上下滑动 | 系统音量 |
| 长按 | 临时倍速播放，松手恢复（倍速在「设置 → 播放 → 长按倍速」选择 1.5/2/3/4×） |
| 双击左/右 | 后退/前进 10 秒 |
| 顶部旋转按钮 | 横屏/竖屏一键切换 |
| 更多 → 画面比例 | 自适应 / 填充 / 拉伸 / 16:9 / 4:3 |
| 更多 → 音轨 | 切换内置音轨（声道）；内置字幕同样在字幕菜单里 |

> MobileVLCKit **3.7.4**（VLC 3.0 2026-09 构建）按 LGPLv2.1 使用，以动态库形式内嵌；官方二进制由 `scripts/fetch-vlckit.sh` 从 VideoLAN 下载并做 SHA256 校验（首次构建约 100MB，之后走缓存）。
> 本项目源码公开，满足 LGPL 对源码与可替换性的要求。

## 六、媒体服务器与云盘

| 来源 | 状态 | 说明 |
| --- | --- | --- |
| 本机目录 | ✅ | 书签授权，全功能文件操作 |
| Emby | ✅ | 官方 API：`/Users/AuthenticateByName`、`/Users/{id}/Items`、`/Videos/{id}/stream` |
| Jellyfin | ✅ | 兼容 Emby 认证与条目接口 |
| 飞牛影视（fnOS） | ⚠️ 兼容模式 | 走 Emby 兼容接口；若设备未开放该接口，请用 WebDAV |
| 极空间影视 | ⚠️ 兼容模式 | 同上 |
| WebDAV | ✅ | PROPFIND / GET / PUT / MKCOL / DELETE / MOVE / COPY；可指定起始目录，并扫描进智能媒体库（番号规则、封面、NFO、字幕全套识别） |
| SMB | ⚠️ 需可选依赖 | 添加 AMSMB2 后可用；播放前会先缓存到本机 |
| 阿里云盘 | ✅ | `openapi.alipan.com`：列目录、获取下载直链 |
| 百度网盘 | ✅ | `/rest/2.0/xpan`：列目录、`filemetas` 取 dlink |
| 123 云盘 | ✅ | `open-api.123pan.com`：列目录、`download_info` 取直链 |
| 115 网盘 | ⚠️ 实验性 | 开放接口，字段随账号权限变化 |
| 天翼云盘 | ⚠️ 建议 WebDAV | 官方接口需要签名，未内置 |
| 中国移动云盘 | ⚠️ 建议 WebDAV | 同上 |
| 光鸭云盘 | ⚠️ 建议 WebDAV | 未公开标准接口 |

云盘登录方式：在「添加来源」中粘贴网页端获取的 `access_token`（阿里云盘还可填写 Drive ID）。
所有密码与 Token 都保存在 **系统钥匙串**（`kSecClassGenericPassword`），不会写入明文 JSON。

## 七、启用 SMB（可选）

iOS 没有系统级 SMB 客户端，本项目通过可选依赖实现：

1. Xcode → `File → Add Package Dependencies…`
2. 输入 `https://github.com/amosavian/AMSMB2`，选择 3.x 或 4.x，添加到 `FMMedia` target；
3. 重新编译。`SMBProvider.swift` 中的 `#if canImport(AMSMB2)` 分支会自动生效。

未添加依赖时，SMB 来源会给出明确提示，其它功能不受影响。若 AMSMB2 的 API 版本有差异，只需调整 `SMBLibProvider` 内部的调用（文件已隔离，约 200 行）。

> SMB 无法提供可随机访问的 HTTP 流，播放时会先完整缓存到 `Caches/SMBStream`，适合中小体积文件。

## 九、开发说明

- 语言模式为 Swift 5（`SWIFT_VERSION = 5.0`），并发检查为 `minimal`，便于在 Xcode 16 下平稳编译；
- 所有网络请求集中在 `Core/Networking`，新增协议只需实现 `RemoteFileProvider` 并在 `ProviderFactory` 注册；
- 本地持久化使用 JSON（`App Support/Data`），封面缓存为磁盘 + 内存两级；
- `Tools/check-syntax.js` 可做括号平衡与常见误用扫描：`node Tools/check-syntax.js FM影媒`；
- `Tools/make-icon.js` 可重新生成 1024×1024 应用图标。

### 已知限制

1. VLC 内核覆盖了几乎所有常见容器，但画中画、AirPlay、杜比视界/全景声的完整支持仍只在系统内核下可用；需要这些特性时请在设置里选「系统」内核。
2. 内嵌字幕（PGS/ASS）在 VLC 内核下由 VLC 自行渲染，样式跟随 VLC；App 的字幕样式设置作用于外挂字幕。
3. 云盘上传未实现（各平台上传链路差异大，且需要分片上传与秒传校验）。
4. 云盘 OAuth 授权页未内置，需要用户自行获取 Token。
5. 飞牛/极空间影视使用兼容模式，未适配其私有协议。
6. 字幕搜索依赖第三方站点，接口变动时可能失效。
7. 首次构建需要联网下载 MobileVLCKit（约 100MB），之后命中缓存。
